# Visual identity

> How the brand appears in everything CompanyOS generates.
> Content, carousel, and post skills read this file before creating any visual.
> Edit it when the brand evolves.

---

## Colors

- **Main background:** Warm paper `#F7F5EF`

- **Highlight / CTA color:** Ocean teal `#006D77` for links, primary actions, and navigation. Lighthouse amber `#E9AD35` for highlights, used sparingly on key findings or selected chart elements.

- **Main text:** Deep ink `#182B36`. Secondary text: Slate `#52636D`

- **Alternative background / cards:** White `#FFFFFF` for cards and charts. Borders and separators: Soft stone `#DADFDC`

- **Forbidden color:** none defined. Never put white text on amber (see below).

**Chart palette:** teal `#006D77`, amber `#E9AD35`, blue `#426BA8`, terracotta `#B95D45`, purple `#8064A2`

---

## Typography

- **Titles and highlights:** Source Serif 4 (400, 600) for report titles, headings, and narrative text

- **Body, subtitles, and buttons:** Source Sans 3 (400, 600) for navigation, chart labels, tables, and captions. Source Code Pro (400) for code and technical identifiers when needed.

- **Title weight:** Semibold (600)

**Report sizes:**
- Body: 18px serif, line height 1.65
- Headings: 32–44px serif, semibold
- Tables and chart labels: 14–16px sans-serif, with tabular numerals for aligned numbers
- Reading width: about 70 characters per line

---

## General style

A readable research publication: warm paper, deep ink, and restrained amber accents. Keep most of each report neutral. Teal handles navigation and emphasis; amber is reserved for what matters most.

## What to NEVER do

- Put white text on amber. Amber always takes dark text.
- Overuse amber. It is an accent, not a fill color.
